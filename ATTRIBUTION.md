# Attribution and scope

This standalone repository contains the Blender implementation, configuration, reports, and rendered artifacts authored for a robotics interview assignment.

The assignment referenced the public [InternRobotics/InternDataEngine](https://github.com/InternRobotics/InternDataEngine) project. That upstream repository was inspected to understand its task YAML, workflow, skill, controller, camera, and logger architecture and to prepare the SimBox/Isaac Sim migration design.

This repository does not redistribute InternDataEngine source code, robot assets, USD task assets, CuRobo content, or datasets. Source paths named in the migration document refer to corresponding locations in the upstream project and are included as technical references only.

Blender, NVIDIA Isaac Sim, CuRobo, PhysX, SimBox, Nimbus, FFmpeg, and other third-party names belong to their respective owners and remain subject to their own licenses and terms.
